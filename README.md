# Deloitte Data Analytics Job Simulation (Forage)

## 📊 Project Overview

This repository showcases my work from the **Deloitte Data Analytics Virtual Experience Program** offered through Forage. The project involves data analysis and creating interactive Tableau dashboards to derive meaningful business insights.

## 🎯 Objectives

- Perform data classification and analysis
- Build interactive Tableau dashboards
- Generate actionable business insights
- Understand real-world data analytics workflows

## 🛠️ Tools & Technologies

- **Tableau** - For data visualization and dashboard creation
- **Excel** - For data cleaning and preprocessing
- **JSON** - For handling telemetry data

## 📁 Repository Contents

- `daikibo-telemetry-data.json.zip` - Project dataset
- `dashboard.png` - Final Tableau dashboard
- `sheet1.png` & `sheet2.png` - Dashboard sheets
- `Deloitte_Forage_Certificate.pdf` - Completion certificate

## 📚 Key Learnings

- Dashboard design best practices
- Business analytics and insight generation
- Professional data storytelling
